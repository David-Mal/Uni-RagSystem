# Allowed knowledge tags

Only these nine values are allowed in synthesis front matter:

- `volume`
- `intensity`
- `rpe`
- `fatigue_load`
- `load_monitoring`
- `progression`
- `frequency`
- `logging`
- `confounders`

Select the values that describe the section's training variables. A document may
have several allowed tags. Do not add synonyms or turn citation keys, exercise
names or review status into tags.

This list implements issue #24 and architecture plan section 4.1. This file,
TEMPLATE.md and SOURCES.md are authoring and provenance references, not synthesis
documents.
